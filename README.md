# SkillProof

> Verify ability, not credentials.

## Problem

Millions of skilled workers lack formal credentials that prove what they can actually do.
At the same time, certificates don't always prove practical competence.

## Solution

SkillProof is an AI-powered skill verification platform that evaluates people through
real-world practical challenges instead of relying solely on certificates.

Users:

1. Select a skill
2. Receive an adaptive challenge
3. Attempt the challenge
4. Receive AI-powered evaluation
5. Learn from personalized feedback
6. Improve and retry
7. Receive a dynamic Skill Passport

## MVP

Our hackathon prototype focuses on:

- Python skill verification
- AI-generated challenges
- AI evaluation
- Personalized feedback
- Adaptive assessment
- Improvement tracking
- Dynamic Skill Passport
