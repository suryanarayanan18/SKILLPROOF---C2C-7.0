Resilient Stream Aggregator

You've been asked to improve a data-processing function used by an asynchronous production microservice handling multi-tenant telemetry bursts.

Production Scenario

The existing legacy function aggregate_payload_stream() suffers from O(N²) memory consumption during unordered timestamp streams and silently crashes when receiving malformed JSON metadata envelopes.

Requirements

  • 01 Temporal Grouping: Group events by 60-second time buckets while preserving chronological order within each bucket.
  • 02 Defensive Validation: Drop malformed payloads with invalid schema, returning a sanitized audit record containing aggregate error counts.
  • 03 Throughput Constraint: Execute aggregation with O(N log K) time complexity or better, where K is the total unique partition keys.

Constraints

Max peak memory: < 64MB
Standard library only (No Pandas)
